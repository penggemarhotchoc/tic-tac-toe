# 🎮 Tic Tac Toe Ultimate

A modern, responsive, and neon-styled Tic Tac Toe web game with intelligent AI, synthesized sound effects, and confetti celebrations.

---

## ✨ Features

- **2 Game Modes**:
  - 🤖 **vs AI**: Play solo with 3 difficulty modes:
    - *Casual (Easy)*: Random play
    - *Smart (Medium)*: Blocks winning streaks and seizes opportunities
    - *Master (Unbeatable)*: Minimax algorithm with alpha-beta pruning
  - 👥 **vs Player**: Pass-and-play local 2-player mode
- **Dynamic Audio FX**: Retro sound effects synthesized natively with the Web Audio API (no external MP3 downloads required, instant playback).
- **Celebrations & Polish**:
  - Particle confetti cannon on victory
  - Animated strike-through line marking winning moves
  - Glowing turn indicator and active player highlighting
  - Persistent scoreboard with `localStorage`
- **Mobile First & Responsive**: Optimized for phones, tablets, and desktop browsers.

---

## 🚀 Quick Local Preview

Open `index.html` directly in your browser or double-click it in your file explorer.

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub.
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** ➔ **"Project"**.
4. Import your `tic-tac-toe` repository.
5. Click **"Deploy"** (no build settings required — it deploys instantly as a static website!).
